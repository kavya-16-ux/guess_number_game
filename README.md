🎯 Guess Number Game

A simple C program game where the user tries to guess a randomly generated number. The program gives hints whether the guessed number is too high or too low until the correct answer is found.

📌 Features
Random number generation
User input based guessing
Hints: "Too High" / "Too Low"
Counts number of attempts
Beginner-friendly C project
🛠️ Tech Stack
Language: C Programming
Concepts Used: loops, conditionals, random number generation
🚀 How to Run
1. Compile the program
gcc guess_game.c -o guess_game
2. Run the program
./guess_game
🎮 How to Play
Program generates a random number (1–100)
You enter your guess
Program gives hints:
📉 Too low
📈 Too high
Keep guessing until you find the correct number
Try to finish in minimum attempts!
